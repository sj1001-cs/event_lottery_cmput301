# event_lottery_cmput301

An Android app for running fair event sign-ups with a lottery. Entrants join a waitlist for an event, the organizer draws winners at random, and winners can accept or decline their invitation.

Built for CMPUT 301 (Fall 2025) 

## Features
- Entrants join and leave an event waitlist
- Organizers create events with a QR code and run the lottery draw
- Notifications for selected and not selected entrants
- Admin tools to manage events, profiles and images
- CSV export of the final entrant list

## Tech
- Java and Android Studio
- Firebase for data and notifications
